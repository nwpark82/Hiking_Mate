# 등산로 데이터 안전성 검토 (2026-11-07)

> 기조: 사용자가 이 데이터를 보고 산행할 때 **길을 잃거나 잘못된 경로로 가는 일이 없어야 한다.**
> 대상: 운영 DB의 등산로 1,030개 전체 (읽기 전용 분석, 데이터는 수정하지 않음)
> 등산로별 결과: `data/trail-review/trail-review.csv` (엑셀에서 열기)

## 1. 결론

| 등급 | 개수 | 의미 |
|---|---|---|
| **A 사용 가능** | 334 (32%) | 경로가 연속되고 시작/끝·유형이 일치. 안내용으로 쓸 수 있음 |
| **B 주의/보정 필요** | 405 (39%) | 300m~1km 끊김, 이름과 실제 모양 불일치(왕복인데 돌아오지 않음), 고도 오류, 소요시간 과소 등 |
| **C 비공개 권장** | 291 (28%) | 1km 이상 직선 점프, 같은 길 여러 번 중복, 좌표 부족 → **그대로 따라가면 길이 없는 곳으로 안내됨** |

- 지금은 C등급 291개를 포함한 **1,030개 전체가 사이트에 공개**되어 있다.
- 문제의 상당 부분은 **원본(공공데이터 GPX)이 아니라 예전 가공 과정에서 생겼다.** 1km 이상 끊긴 256개 중 170개(66%)는 원본이 정상이다. → 원본에서 다시 만들면 복구 가능
- 원본 GPX에는 등산로마다 평균 30개의 **이정표(갈림길·위험지역·국가지점번호 등)** 가 있으나 서비스에서 쓰지 않고 있다.

## 2. 판정 기준

| 분류 | 항목 | 기준 | 등급 영향 |
|---|---|---|---|
| **시작과 끝** | 유형 불일치(열림) | 왕복/순환인데 시작-끝 500m 이상 | B |
| | 유형 불일치(닫힘) | 편도인데 시작-끝 150m 이내 | 참고 |

| **중간 누락** | 끊김 | 연속 좌표 간격 ≥ max(100m, 간격 중앙값×8) | 100~300m 참고 / 300m~1km B / **1km 이상 C** |
| **인위적 가공** | 경로 중복 | 같은 길을 2.6배 넘게 반복 (왕복은 2배가 정상) | C |

## 3. 분류별 결과

### 3.1 시작과 끝
- **"(왕복코스)" 261개 중 156개(60%)가 출발점으로 돌아오지 않는다.** 이름만 보고 차를 출발지에 두면 낯선 곳에서 하산하게 된다. → 가장 시급한 표시 오류
- 순환(CIRCULAR_PARTIAL)으로 분류된 418개 중 125개도 끝이 열려 있다.
- 정/역방향 쌍 384개 중 164개는 서로 시작/끝이 맞지 않는다(한쪽만 가공됨).
- 정상에서 출발하는 코스 1개(가야산 5번 왕복코스), 편도인데 정상에서 끝나는 코스 9개.

### 3.2 중간 누락
| 최대 끊김 | 등산로 수 |
|---|---|
| 100m 이상 | 425 |
| 300m 이상 | 353 |
| 1km 이상 | 256 (최대 55km) |

- 끊긴 구간은 지도에서 **직선**으로 그려진다. 사용자가 그 직선을 따라가면 계곡·절벽 등 길이 없는 곳으로 가게 된다.

### 3.3 인위적 가공
- 같은 길이 2.6배 넘게 반복된 경로 155개 (예: 백두대간트레일 2번 — 실제 4.5km가 4,535km로 계산될 정도로 중복)
- 원본보다 1.6배 이상 길어진 경로 330개 (왕복 경로 덧붙이기, 갭 채우기 과정의 부작용)
- 원인: `DATA_PROCESSING_HISTORY.md` 의 갭 채우기·왕복 자동 생성 스크립트들이 여러 번 덮어씀

### 3.4 GPS/고도

## 4. 원인: 원본 vs 가공

| 등급 | 원본 정상 | 원본 결함 | 원본 없음 |
|---|---|---|---|
| A | 318 | 15 | 1 |
| B | 279 | 98 | 28 |
| C | 116 | 163 | 12 |

- **C등급 116개 + B등급 279개는 원본이 정상** → 원본에서 다시 변환하면 대부분 A로 복구될 가능성이 높다.
- **원본 자체에 결함이 있는 것(B 98, C 163)** 은 원본 GPX가 여러 구간(trkseg)으로 나뉘어 있거나 기록이 끊긴 경우 → 구간 분리 표시, 수작업 보정, 또는 비공개.

## 5. 이번 분석으로 확인하지 못한 것

- **실제 등산로와의 일치**: 지도 데이터(산림청 등산로 노선, 카카오맵)와의 대조 필요
- **출발점 접근성**: 출발점이 도로·주차장·정류장 근처인지 (원본 이정표의 '주차장' 113개, 카카오 장소 검색으로 보강 가능)
- **통제/폐쇄 구간**: 국립공원 탐방로 통제, 계절 입산 통제 정보
- **난이도 적정성**: 고도 오류가 있는 코스는 난이도도 재산정 필요

## 6. 개선 방향 (제안)

1. **즉시 (안전)**: C등급 비공개 또는 경고 표시, 등산로 상세에 "참고용 경로 — 현장 이정표를 우선하세요" 안내
2. **원본 기반 재구축**: 원본 GPX → 단일 변환 파이프라인(가공 최소화)으로 다시 생성. 정/역방향은 하나로 합치고 "반대 방향" 보기만 제공. 왕복 여부는 이름이 아니라 실제 시작-끝으로 표시
3. **원본 결함 코스 처리**: 구간 분리 표시 또는 관리자 화면에서 수작업 보정 후 공개
4. **이정표 활용**: 갈림길·위험지역·국가지점번호·화장실을 지도에 표시 (길 잃음·조난 대응)
5. **표시 정보 재계산**: 거리·소요시간·누적 상승·난이도를 보정된 경로 기준으로 재산정
6. **데이터 품질 게이트**: 이 분석을 등급 기준으로 고정하고, 공개 전 자동 검사

## 7. 재현 방법

