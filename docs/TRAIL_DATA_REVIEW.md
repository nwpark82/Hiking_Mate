> 대상: 운영 DB의 등산로 1,030개 전체 (읽기 전용 분석, 데이터는 수정하지 않음)

### 운영자 기준
- **시작/끝**: 양 끝이 **산 초입**이면 유효. 출발·도착이 멀리 떨어져 있어도 초입이면 유효. 왕복은 끝이 출발점 인근(500m)이어도 유효
- **경로**: 300m 이상 끊김, 같은 길 3회 이상 반복(경로의 10% 초과)이 없어야 함. 좌표 순서가 원본과 달라도 지도상 연속이면 유효
- **정상(또는 중턱)에서 끝나는 편도 → 왕복으로 전환** (추후 정상에서 만나는 등산로끼리 사용자 조합 기능 예정)

- 순서 꼬임만 있는 83개는 원본 순서로 다시 만들면 끊김이 사라짐

**같은 길 반복**
- 등산로 사이의 중복이 아니라 **한 등산로 안에서 같은 길을 여러 번 지나는 것**이다. 정/역방향 쌍(설계상 같은 길)을 제외하면 서로 거의 같은 등산로는 0쌍
- 같은 길을 3회 이상 지나는 구간이 10%를 넘는 등산로 154개 — **원본 기록에는 이런 반복이 전혀 없음(0개)**. 경로 길이가 원본의 1.5~4배(중앙값 2.5배)로 늘어나 있어 예전 갭 채우기·왕복 생성 스크립트가 여러 번 덧붙인 결과로 판단
- 원본으로 다시 만들면 해소됨

**고도 급변**
- 급변 지점 3,545곳 중 끊김 인접 57, 순서 꼬임 1, **원본 GPS 고도 오차 3,487**
- DB 고도는 원본 GPX 고도와 동일(차이 중앙값 0m) — 위·경도 끊김이나 순서 문제가 아니라 원본 기록 단계의 고도 측정 오차. 고도 평활화 또는 수치표고모델(DEM) 고도로 교체 필요

**소요시간·거리**
- 안내 거리는 현재 DB 경로 길이와 같다(99~100%). 따라서 경로가 가공 중 부풀려지면 안내 거리도 같이 부풀려져 있다 (원본 대비 상위 10%는 2.25배 이상)
- 안내 소요시간은 1km당 10~79분으로 편차가 커서 거리로 계산한 값이 아니라 원본 기록 시간으로 보임
- 소요시간 과소 73개: 경로 오류로 추정치가 과대 55 / 상승고도가 큰 코스 10 / 기타 8
- 경로 보정 후 거리·소요시간·상승고도를 다시 계산해야 함

### 신뢰도와 공개 (운영자 결정, 2026-11-08)

- **신뢰 등산로만 공개**: 경로 판정 '사용 가능'(왕복 전환 대상은 전환 후) + 안내 소요시간이 표준 추정치(거리 4km/h + 상승 500m/h, 고도 평활화)의 **0.6~2.5배** 이내
- 안내 소요시간은 원본 기록 시간(휴식 포함)이라 추정치보다 긴 것이 정상(중앙값 1.68배). 짧은 쪽은 일몰 위험이 있어 하한을 엄격하게 둠
- 결과: 신뢰 450 / 비신뢰 580 (허용 범위 0.7~2배면 404, 0.5~3배면 492)
- 정상/중턱에서 끝나는 편도 83개는 왕복(올라간 길로 하산)으로 전환. 소요시간은 기존 값 × (왕복 추정 ÷ 편도 추정)
- 비신뢰 등산로는 비공개(관리자 화면에서만 보임). 사유는 `trails.quality_note` 에 저장
- 모든 등산로 상세에 안전 안내(참고용 경로, 현장 이정표 우선, 일몰 전 하산) 표시

## 5. 이번 분석으로 확인하지 못한 것

- **실제 등산로와의 일치**: 지도 데이터(산림청 등산로 노선, 카카오맵)와의 대조 필요
- **출발점 접근성**: 출발점이 도로·주차장·정류장 근처인지 (원본 이정표의 '주차장' 113개, 카카오 장소 검색으로 보강 가능)
- **통제/폐쇄 구간**: 국립공원 탐방로 통제, 계절 입산 통제 정보
- **난이도 적정성**: 고도 오류가 있는 코스는 난이도도 재산정 필요

## 6. 개선 방향 (제안)

1. **즉시 (안전)**: C등급 비공개 또는 경고 표시, 등산로 상세에 "참고용 경로 — 현장 이정표를 우선하세요" 안내
2. **원본 기반 재구축**: 원본 GPX → 단일 변환 파이프라인(가공 최소화)으로 다시 생성. 정/역방향은 하나로 합치고 "반대 방향" 보기만 제공. 왕복 여부는 이름이 아니라 실제 시작-끝으로 표시
3. **원본 결함 코스 처리**: 구간 분리 표시 또는 관리자 화면에서 수작업 보정 후 공개
4. **이정표 활용**: 갈림길·위험지역·국가지점번호·화장실을 지도에 표시 (길 잃음·조난 대응)
5. **표시 정보 재계산**: 거리·소요시간·누적 상승·난이도를 보정된 경로 기준으로 재산정
6. **데이터 품질 게이트**: 이 분석을 등급 기준으로 고정하고, 공개 전 자동 검사
